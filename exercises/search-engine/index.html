Search Engine — Requirements Exercise

Design brief: Design a service that lets users search a large corpus of documents and returns relevant results ranked by relevance.

Functional Requirements

  • Users can submit free-text queries and receive a ranked list of matching documents.
  • The system must return results ordered by relevance to the query.
  • Users can paginate through results beyond the first page.
  • The system must support multi-word queries and match documents containing those terms.
  • The system must provide query auto-complete and suggestions as the user types.
  • The system must handle misspellings and offer "did you mean" corrections.
  • Users can filter and narrow results by attributes such as date, category, or source.
  • The system must display a short snippet for each result with matching terms highlighted.
  • New and updated documents must become searchable within a bounded ingestion delay.
  • The system must support removal of documents so deleted content no longer appears in results.
  • The system must record query and click activity to support relevance measurement.

Non-Functional Requirements

  • The system must index a corpus of at least 1 billion documents.
  • Query latency should be under 200 ms end to end (p99).
  • The system must sustain 100,000 queries per second at peak.
  • Availability target of 99.95% for the query-serving path.
  • Newly ingested documents should be searchable within 60 seconds of arrival.
  • Ranking quality must remain stable, with high-relevance results appearing in the top positions.
  • The system must scale horizontally as the corpus and query volume grow.
  • Index storage and serving costs should remain efficient at billion-document scale.
  • The system must be resilient to node failures without losing searchable coverage.

Assumptions & Out of Scope

  • Assume documents are primarily text; deep image, audio, and video search are out of scope.
  • Web crawling and document acquisition are assumed to be handled by an upstream pipeline.
  • Personalized ranking per individual user is excluded for this exercise.
  • Ad placement and monetization of results are out of scope.
  • Assume queries are in a single supported language unless otherwise specified.
